# 💻 Atividade em C++ / Linguagem C

## 📌 Descrição

Este projeto foi desenvolvido como atividade acadêmica com o objetivo de praticar conceitos iniciais de programação, utilizando entrada e saída de dados, variáveis, estrutura condicional e interação com o usuário.

O programa exibe uma mensagem inicial, solicita que o usuário digite sua idade e, em seguida, verifica se a idade informada é maior que 10 ou menor/igual a 10.

---

## ⚙️ Funcionalidades

✔ Exibe a mensagem `Olá, mundo!`;  
✔ Solicita a idade do usuário;  
✔ Lê a idade digitada usando `scanf`;  
✔ Verifica se a idade é maior que 10;  
✔ Exibe uma mensagem de acordo com a idade informada;  
✔ Utiliza `setlocale` para permitir caracteres especiais no Windows;  
✔ Usa `system("pause")` para manter a tela aberta após a execução.  

---

## 🛠️ Tecnologias Utilizadas

➤ Linguagem C / C++  
➤ Biblioteca `stdlib.h`  
➤ Biblioteca `stdio.h`  
➤ Biblioteca `locale.h`  

---

## 🧩 Estrutura do Código

O código é composto por:

✦ Inclusão de bibliotecas;  
✦ Função principal `main`;  
✦ Configuração de idioma com `setlocale`;  
✦ Impressão de mensagens com `printf`;  
✦ Leitura de dados com `scanf`;  
✦ Estrutura condicional `if` e `else`;  
✦ Comando `system("pause")` para pausar o programa no Windows.
